# Selenium Login Automation

Browser automation project using Python and SeleniumBase to automate login workflows.

## Requirements

* Python 3.12+
* Google Chrome
* Git

## Installation

```bash
git clone <repository-url>
cd selenium-login-automation

python -m venv venv
```

**Windows (PowerShell):**

```powershell
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```bash
python scrap.py
```
